# RetinaGroundBench

**A Visual Grounding Benchmark for Retinal OCT with Multimodal Large Language Models**

This repository will host the official release of **RetinaGroundBench**, the first
benchmark for biomarker visual grounding in retinal optical coherence tomography (OCT).

The benchmark comprises **815 OCT B-scans** exhaustively annotated by ophthalmologists
with **4,537 bounding boxes** spanning **13 clinically relevant biomarkers** across
**8 retinal diseases**. Alongside the benchmark we release **AggIoU**, an overlap metric
and matching criterion tailored to the multi-box prediction behaviour of MLLMs, and
**RetGrounder**, an 8B model domain-adapted to retinal OCT as an open baseline.
